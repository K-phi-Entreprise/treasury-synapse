# Treasury Synapse

A 3D map of treasury and finance professionals built only from public sources: who speaks about what, on which systems, and who appeared with whom. No LinkedIn data, no photos, every fact carries the URL it came from.

## Three angles on one set of facts

- Social: public co-appearance (same episode, panel, webinar, team). Not acquaintance.
- Topics: people around the topics they speak about and the systems they use, sell or implement. Size is public footprint.
- Connections: declared by people themselves, pending until the owner validates.

## Layout

- `db/schema.sql`: Postgres schema (people and their facts, occasions, co-appearances, connections, submissions, leads, runs, vendors, quotas) and the three angle views.
- `scripts/migrate.js`: applies the schema (idempotent). `scripts/import.js`: loads a dump of the former artifact store; `--if-empty` makes it a no-op on a filled store.
- `server.js`: the map at `/`, `GET /api/graph`, `POST /api/connections`, `POST /api/submissions`, admin review endpoints under `/api/admin/*` (header `x-admin-token`).
- `public/index.html`: the map page, generated by `scripts/build-page.py` from the artifact page.
- `data/seed/dump.json`: the store as of 8 Nov 2026 (1,981 people, 3,795 edges, 62 vendors, 39 runs, 41 leads). Public professional facts only.
- `chat.js`: the map's chat on the K-phi Anthropic key. The page runs the `find_people` tool on the graph it already holds; the server owns the prompt, the single tool, the model (`CHAT_MODEL`, Haiku by default), 700 output tokens, a signed token for the tool loop, and the limits: `CHAT_PER_VISITOR` questions a day per visitor (20) and `CHAT_DAILY_CAP` for everyone (1,500, about $30 a day at most).
- `render.yaml`: Render Blueprint (web service, Postgres, Frankfurt). The pre-deploy step migrates and seeds.

## Run locally

    export DATABASE_URL=postgres://postgres@localhost:5432/synapse
    npm install && npm run migrate && npm run import data/seed/dump.json && npm start

## Tests

    DATABASE_URL=... ADMIN_TOKEN=x npm test

The tests drop and recreate the public schema of the database they are pointed at.

## Rules the code enforces

- Nothing a visitor sends is instant: declarations and submissions are pending until reviewed.
- A removal request hides the card immediately; deletion waits for approval, rejection restores the card.
- Per-visitor daily limits on declarations, submissions and (D2) chat questions.
